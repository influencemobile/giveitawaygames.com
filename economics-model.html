Model: each month, (combined modeled installs from the Install Model page ÷ 12) × engaged-install rate = new engaged players added to the base; the existing base loses the churn rate each month before that addition. Steady-State MAU is where the base would flatten out if inflow and churn both held constant indefinitely (new engaged players ÷ churn rate). "Average MAU" (in the revenue banner above) is the mean across this full 24-month run, and gross revenue is MAU × $5.50/month.
